## 体例

一篇一页，每篇十二节：本篇导读、经文、字义与句读、今译、篇旨、注疏、分寸与边界、义理、时代之问、跨典、存疑、双卡与图；篇末附「少年读」一段（一百至二百字，加一件事、三个问题）。四层分离：`【序】` 书序、`【经】` 原文、`【注】` 注疏、`【义】` 义理、`【用】` 今用，一段只归一层。

短篇正文 1,500–2,500 字，长篇正文 4,000–6,000 字；每篇至少一张义理示意图（手写 SVG，纸墨五色，不绘神像、祖师像）。

## 正经与别录

- **正经**：今文二十八篇（按汉儒旧次合并：尧典含舜典、皋陶谟含益稷、盘庚三篇为一、顾命含康王之诰），注疏本分题则为三十三目。
- **存疑别录**：古文二十五篇。经文照录、源流与存疑说明齐备，义理可读，但不混入正经的道统叙述，也不销毁。每篇存疑节含真伪总案、若为真古文献的价值、本书处置三条。
